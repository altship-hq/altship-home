Start building ↗How it works

From spec to server in four steps.

How it works
  1. 01

    Import your spec

    Point us at an OpenAPI 3.x spec by URL or path. We parse and validate it, and flag anything an agent would trip over.

  2. 02

    Review the tools

    Every operation becomes a tool, grouped by namespace. Destructive and sensitive operations are flagged and start unselected.

  3. 03

    Generate the server

    Get an agent-friendly MCP server for the tools you picked — source, tests and deployment docs included.

  4. 04

    Deploy it

    Ship to a managed endpoint on Vercel, or take the code and run it on your own infrastructure.
